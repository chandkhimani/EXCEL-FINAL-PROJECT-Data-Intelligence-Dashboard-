## 1. ✨ Project Overview

**Data Intelligence Dashboard** is an academic data analysis project developed using Microsoft Excel. It focuses on analyzing customer transaction records and transforming raw data into meaningful business insights.

The project uses Excel formulas, date and time functions, filtering, conditional formatting, data analysis techniques, and interactive visualizations to understand customer behavior, revenue performance, product demand, and regional sales.

The final objective is to present important business information through a structured and easy-to-understand Excel dashboard.

## 2. 🎯 Project Objectives

- Analyze customer transaction data.
- Calculate total revenue and identify top customers.
- Identify the most frequently purchased products.
- Analyze regional sales performance.
- Apply advanced Excel formulas and functions.
- Compare and match information between two lists.
- Use What-If Analysis for business scenarios.
- Perform Linear Regression using the Data Analysis ToolPak.
- Create an interactive dashboard with charts, PivotTables, and filters.
- Present findings through data analysis and storytelling.

## 5. 🧮 Excel Functions & Concepts

The project covers the following Excel functions and concepts as specified in the assignment.

### Date & Time Functions

| Function | Application |
|:--|:--|
| `TODAY()` | Returns the current date |
| `NOW()` | Returns the current date and time |
| `DATEDIF()` | Calculates the difference between two dates |
| `EOMONTH()` | Returns the last date of a month |

### Data Filtering & Text Functions

| Function / Feature | Application |
|:--|:--|
| `FILTER()` | Returns multiple records based on conditions |
| Text Functions | Creates abbreviations from text values |
| Matching Lists | Identifies common names between two lists |
| Repeating Values | Finds frequently occurring names or products |

### Conditional Formatting

- Uses visual formatting to highlight important values.
- Applies icon sets and arrows.
- Helps identify high and low values quickly.

### Timestamp Creation

Uses `NOW()` and iterative calculation concepts to create timestamps.
